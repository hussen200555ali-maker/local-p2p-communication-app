# مجلد الأصوات

يحتوي هذا المجلد على ملفات الصوت المستخدمة في التطبيق.

## الملفات المطلوبة

### نغمة الرنين
- `ringtone.mp3`: نغمة الرنين للمكالمات الواردة

### الأصوات الأخرى
- `message_sent.mp3`: صوت إرسال الرسالة
- `message_received.mp3`: صوت استلام الرسالة
- `call_ended.mp3`: صوت انتهاء المكالمة
- `call_connected.mp3`: صوت بدء المكالمة

## ملاحظات

- يجب أن تكون جميع الملفات بصيغة MP3 أو WAV
- يفضل أن تكون مدة الأصوات قصيرة (1-3 ثواني)
- يجب ضغط الملفات لتقليل حجم التطبيق
