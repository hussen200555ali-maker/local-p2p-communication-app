## 4. تفاصيل التعديلات الحرجة

### 4-1 شروط المنصة (Platform guards)
8 ملفات تم تحديث شروط `Platform.isWindows` فيها لتشمل Linux أيضاً. جميعها تتبع النمط:
```dart
if (Platform.isWindows || Platform.isLinux) { ... }
```
أو:
```dart
if (!Platform.isWindows && !Platform.isLinux) { ... }
```

### 4-2 إشعارات Linux
تمت إضافة كتلة تهيئة `LinuxInitializationSettings` في `system_notification_service.dart:34-50`:
- تستخدم `defaultActionName: 'فتح التطبيق'`
- محمية بـ `try-catch` — لا تتعطل إذا فشلت الإشعارات
- تعود `return` بعد التهيئة (لا تنفذ كتلة Android)

### 4-3 CMake + GTK Identity
- `linux/CMakeLists.txt`: اسم الملف `Alshami` ومعرف التطبيق `com.alshami.app`
- `linux/runner/my_application.cc`: عنوان النافذة `"الشامي"` + أيقونة GTK من `resources/app_icon.png`
- `linux/runner/resources/app_icon.png`: أيقونة PNG (64x64+) — مأخوذة من `assets/icons/app_icon.png`

### 4-4 تحذير Kali
تمت إضافة بطاقة تحذير أمني في `settings_screen.dart` تظهر فقط على Linux:
```
⚠️ تحذير أمني
هذا التطبيق مخصص للتواصل الخاص على شبكة محلية موثوقة.
الشبكات العامة أو المعادية قد تعرض اتصالاتك للخطر.
```

## 6. أوامر البناء على Kali (للرجوع إليها)

```bash
# المتطلبات
sudo apt update
sudo apt install -y libgtk-3-dev liblzma-dev pkg-config cmake ninja-build clang
flutter config --enable-linux-desktop

# البناء
flutter build linux --release
# الناتج: build/linux/x64/release/bundle/Alshami
```
