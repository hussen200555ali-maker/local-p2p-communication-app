تم إكمال نقل تطبيق "تواصل محلي" إلى منصة Windows مع سد جميع الفجوات بين Windows/Mobile. التطبيق يعمل بكامل وظائفه على كلا المنصتين بدون تغيير في الكود المشترك — جميع تغييرات Windows محمية بواسطة `Platform.isWindows`.

## 2. الفجوات والإصلاحات

### G1 🔴 — `Permission.storage` غير محمي

| البند | التفاصيل |
|-------|----------|
| **الملف** | `lib/features/chat/screens/chat_screen.dart:186` |
| **الوصف** | `Permission.storage.request()` يستدعي Android-specific API بدون حماية `Platform.isWindows`. أي ضغطة على "إرسال ملف" على Windows تسبب تعطل التطبيق. |
| **الإصلاح** | إضافة `if (!Platform.isWindows)` حول كتلة الصلاحية. على Windows، يستخدم `FilePicker.platform.pickFiles()` مباشرة بدون طلب صلاحية. |
| **التحقق** | ✅ تم — `flutter analyze` 0 errors، `flutter build windows --release` ناجح |
| **التعزيز** | تم تدقيق جميع استدعاءات `Permission.*` في المشروع — موقع واحد فقط (`splash_screen.dart:26`) كان لديه `Permission.location.request()`، وكان **محمياً بالفعل** بشرط `if (!Platform.isWindows)`. |

### G3 🟡 — مجلد الأصوات غير معلن في `pubspec.yaml`

| البند | التفاصيل |
|-------|----------|
| **الملفات** | `assets/sounds/`، `pubspec.yaml:50-52` |
| **الوصف** | مجلد `assets/sounds/` غير مُعلَن تحت `flutter: assets:` في `pubspec.yaml` (فقط `images/` و `icons/` معلنان). ملفان يستخدمان `AssetSource('sounds/ringtone.mp3')` — `call_audio_service.dart:59` و `call_settings_screen.dart:63` — وكلاهما يفشل بصمت. |
| **الإصلاح** | إضافة `- assets/sounds/` إلى `pubspec.yaml`، وإنشاء نغمة رنين WAV (69 KB، 1.6 ثانية، نغمات A-C-E-G-E-C-A-C مع هارمونيكس)، وتحديث مراجع AssetSource من `.mp3` إلى `.wav`. |
| **التحقق** | ✅ تم — `flutter build` يتضمن المجلد الجديد |
